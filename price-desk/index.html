Call this network from your own agentic website

Pharmacies, hospitals, NGOs and health apps: add the price desk to your agent network instead of copying the list. The network runs in your visitor's browser with your visitor's AI key; this site never sees the key.

1. In your network JSON, add a link slot and use it as a tool:

"link_slots": { "jan_aushadhi_prices": { "description": "Jan Aushadhi Price Desk" } },
"tools": [ { "name": "your_front_agent", "tools": ["jan_aushadhi_prices"], ... } ]

2. In your links.json, bind it to this site:

{ "version": 1, "networks": { "your_network": { "jan_aushadhi_prices": "/jan_aushadhi_prices" } } }

3. Add this origin to allowed_peers in your agent-manifest.json, and serve runtime/sandbox-worker.js with the CSP header from our _headers (needed for the sandboxed price tool). Public files: agent-manifest.json · jan_aushadhi_prices.network.json · tools/price_lookup.js (SRI-pinned) · data/products.json.
